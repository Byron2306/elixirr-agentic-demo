# Elixirr Agentic Demo

A compact interview demonstration of four real engineering systems:

1. **Vesper / DIO** — business intent to governed action.
2. **BEAST** — governed coding-agent execution and verification.
3. **Seraph** — MCP action boundaries with VNS independent observation.
4. **ARDA / Valinor** — hardware-rooted and kernel-authoritative execution trust.

This repository is an **integration harness**, not a reimplementation of the source systems. Each act is exposed through a thin adapter and an explicit scenario. Evidence imported from source repositories must preserve provenance and claim boundaries.

## Demo thesis

> Useful AI is more than model output: reasoning, tools, authority, observation, verification and execution trust must remain distinguishable.

## Planned flow

```text
BUSINESS AGENT
    ↓
ENGINEERING AGENT
    ↓
ADVERSARIAL CONTROL
    ↓
TRUSTED EXECUTION
```

## Repository contract

- Prefer live local integrations.
- Never silently substitute simulation for live execution.
- Recorded/replayed evidence must be labelled.
- Keep consequential actions bounded and reversible.
- Preserve source repository/ref/path for imported evidence.
- A model response is not proof.
- Demo convenience must not widen source-system authority.
